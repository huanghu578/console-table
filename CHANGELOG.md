# Changelog

## [0.1.0] - 2026-09-13

### Added
- Initial release.
- `Style::Simple` and `Style::Boxed` border styles.
- `Align::Left`, `Align::Right`, `Align::Auto`.
- `max_cell_width` truncation with ASCII `...`.
- `header_color` and `body_color` from a 16-color ANSI palette.
- CJK/Unicode-aware width via `unicode-width`.
